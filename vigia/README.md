4. O Mac recusa por conta própria qualquer sugestão que mexa em portão, plugin ou mensagem a lead, mesmo que esteja no canal, e avisa o Daniel de manhã.
5. Se o canal virar mais barulho que ajuda, o Mac para de ler e avisa.
